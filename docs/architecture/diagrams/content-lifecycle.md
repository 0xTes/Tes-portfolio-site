# Content Lifecycle

## Purpose

Illustrates how an article moves from publication to the website.

---

```text
Draft
  │
  ▼
Publish
(Substack)
  │
  ▼
RSS Feed
  │
  ▼
Fetch
  │
  ▼
Transform
  │
  ▼
Validate
  │
  ▼
Render
  │
  ▼
SEO
  │
  ▼
Live Website
```

---

## Key Points

- Articles are authored only in Substack.
- Validation occurs before rendering.
- SEO is generated automatically.
- Published articles appear natively on the website.
